Get the application URL by running:
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "coolify.name" . }},app.kubernetes.io/instance={{ .Release.Name }}" -o jsonpath="{.items[0].metadata.name}")
  export CONTAINER_PORT=$(kubectl get pod --namespace {{ .Release.Namespace }} $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME 8080:$CONTAINER_PORT

  Then visit: http://localhost:8080

📋 Post-Installation Steps:

1. Create your first admin account by visiting the Coolify URL
2. Add your Docker servers via SSH in the Servers section
3. Deploy your first application!

⚠️  Important Notes:

- The "localhost" server feature is NOT available when running on Kubernetes
- You must add external Docker servers as deployment targets
- Coolify connects to servers via SSH, so ensure network connectivity
